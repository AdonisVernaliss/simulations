# Simulations

Interactive scientific simulations designed for real-time use in modern browsers.

The project focuses on clear physical models, responsive controls, and predictable performance across desktop and mobile devices.

## First simulation

Orbital Mechanics Lab explores gravitational systems through configurable bodies, stable numerical integration, orbital trails, and physical diagnostics.

## Development status

The project is under active development. Setup and usage instructions will be added with the first runnable release.
